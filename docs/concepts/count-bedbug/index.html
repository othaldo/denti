Der Umhang-Graf · Entwurf C

Drei Bettwanzen-Vampire, jeweils links in Ruhe und rechts mit geöffnetem Umhang. Große Flächen, ein Fangzahn, keine Krone. C ist ausgewählt: Die versetzten Umhangseiten geben dem Grafen eine eigene Form und eine klare Schlagrichtung.
