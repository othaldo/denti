# Kronenvasallen

Drei eigenständige Imperator-Minibosse, erzeugt mit dem eingebauten
`image_gen`-Tool. Stilreferenz: `assets/enemies/emperor_court/portrait.png`.
Die Referenz und die erzeugten PNG-Originale wurden nicht überschrieben.

| Figur | Originaldatei |
| --- | --- |
| Kronenlanze | [crown_lancer.png](crown_lancer.png) |
| Siegelhüter | [seal_keeper.png](seal_keeper.png) |
| Reichsrichter | [royal_justiciar.png](royal_justiciar.png) |

Das vollständige finale [Promptset](prompts.json) enthält Modus,
Stilreferenz und die drei Einzelprompts. Alle PNGs besitzen einen echten
Alphakanal. Godot importiert sie mit Mipmaps und einem 512-Pixel-Limit;
die Quelldateien bleiben in ihrer erzeugten Auflösung erhalten.
